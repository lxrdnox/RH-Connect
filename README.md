# RH CONNECT Portal Corporativo

**O RH Connect é um portal de Recursos Humanos desenvolvido com o objetivo de centralizar e facilitar o acesso a informações e serviços relacionados à gestão de pessoas dentro de uma empresa.**

**O projeto foi desenvolvido como uma atividade prática de Front-End, utilizando tecnologias web para criar uma interface intuitiva, organizada e de fácil navegação.**
