# PORTAL RH CONNECT
RH CONNECT
Portal corporativo de Recursos Humanos para centralizar serviços, informações e solicitações dos colaboradores em um único ambiente.

O RH CONNECT é um projeto de portal de RH com interface web e servidor Node.js. A proposta é facilitar o acesso dos colaboradores aos serviços internos e oferecer à equipe de RH ferramentas para organizar atendimentos, comunicados e informações administrativas.
Status do projeto: versão demonstrativa em desenvolvimento. Alguns módulos e integrações podem utilizar dados simulados. Não utilize dados pessoais ou documentos reais nesta versão.
