# Guia rápido de apresentação — RH CONNECT

## Antes de apresentar

1. Abra o endereço publicado no GitHub Pages.
2. Atualize a página com `Ctrl + F5`.
3. Entre primeiro como colaborador: `colaborador@rhconnect.com` / `123456`.
4. Depois saia e entre como RH administrador: `rh@rhconnect.com` / `123456`.

Os botões de acesso rápido na tela de login também preenchem os dados.

## Roteiro sugerido (5 a 7 minutos)

### 1. Experiência do colaborador

- **Meu painel:** apresente os indicadores, atividades recentes e comunicados.
- **Meus holerites:** abra o demonstrativo de novembro e mostre a opção de imprimir/salvar como PDF.
- **Vale alimentação:** mostre o crédito de exemplo de R$ 650,00.
- **Ponto web:** demonstre o fluxo de registro de entrada, intervalo, retorno e saída. O registro inicial do dia já vem parcialmente preenchido para facilitar a demonstração.
- **Central de solicitações:** abra um novo chamado e mostre o histórico.
- **Agenda psicológica:** reserve um dos horários disponíveis.
- **Mural de comunicados:** mostre as publicações.

### 2. Experiência do RH administrador

- **Funcionários:** consulte o diretório, cadastre um colaborador e exporte a lista CSV.
- **Holerites e benefícios:** cadastre um registro para demonstrar a rotina do RH.
- **Solicitações:** altere o status de um chamado para “Em andamento” ou “Concluída”.
- **Agenda psicológica:** adicione um novo horário.
- **Mural de comunicados:** publique um aviso.
- **Relatórios:** mostre os indicadores consolidados.
- **Usuários e permissões:** apresente os dois perfis de acesso.

## Importante

Esta versão é um protótipo funcional para apresentação. Os registros pré-carregados são fictícios e as alterações ficam salvas apenas no navegador atual (`localStorage`). O projeto ainda não está conectado ao Firebase, e as telas de holerite e ponto não substituem sistemas oficiais. Não utilize dados reais de funcionários.
